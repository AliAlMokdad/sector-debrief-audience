# The Sector Debrief · Audience

A static page showing the audience of The Sector Debrief per platform: the YouTube channel, the podcast feed, and the website in Google Search.

The numbers come from the platforms' own exports (YouTube Studio, Spotify for Creators, Google Search Console). `build/build_data.py` reads the export files and writes `data/audience.json`; the page renders from that file with no libraries. Updated monthly.
